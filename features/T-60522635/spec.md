Branch di partenza: meta-repo → `e2e-base`, api → `e2e-base`, web → `develop`.

## Criteri di accettazione
- WHEN la feature è completata, il `README.md` del meta-repo SHALL contenere un'intestazione `## Prova branch di partenza`.
- WHEN la feature è completata, la sezione `## Prova branch di partenza` SHALL contenere esattamente una riga di testo non vuota.
- WHEN la feature è completata, il resto del `README.md` SHALL restare invariato.
- WHEN la feature è completata, i puntatori e il codice dei submodule `api` e `web` SHALL restare invariati.
